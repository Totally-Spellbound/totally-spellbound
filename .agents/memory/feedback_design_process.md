Do NOT ask abstract design questions (hex values, "how dark", font choices). Instead, open the relevant live reference or local storefront in the native Codex browser, let Andrew point out what he likes or annotate what is wrong, and inspect the actual CSS/design values from the page.

**Why:** Andrew is a designer who works visually, not from abstract specs. He needs to SEE it and react to it. Asking "how dark should the background be?" without visual context is useless — he wants to inspect Monopo's actual background color and say "that one".

**How to apply:** Use the native Codex browser first for localdev and ordinary references; use Chrome DevTools only when a logged-in Chrome session is genuinely required. Take screenshots, inspect computed styles and walk through elements together. Monopo (monopo.vn) remains the primary external reference and Wope is secondary when those references are relevant. The repository `DESIGN.md` and the current storefront are the authority for Totally Spellbound.
